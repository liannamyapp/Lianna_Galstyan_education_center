# CRM և բիզնեսի աճի պլան

Այս փաստաթուղթը բացատրում է, թե ինչպես է աշխատում կայքի CRM-ը, ինչ ալգորիթմներով է այն որոշումներ կայացնում և ինչ քայլերով աճեցնել կրթական կենտրոնը առաջիկա 90 օրում։ Նույն տեքստը կա ադմինում՝ **CRM → Աճի պլան**։

---

## 1. Ինչպես է աշխատում համակարգը

```
Instagram · TikTok · Facebook · Google · ընկերոջ խորհուրդ · բաց դաս
                     │  (UTM պիտակներ, Telegram-ի հղում, Lead Ads)
                     ▼
  Կայքի ձևեր · WhatsApp · Telegram · Instagram Direct · Messenger · զանգ
                     │
                     ▼
               ┌───────────┐   ավտոմատ ողջույն + առաջադրանք «զանգել 30 րոպեում»
               │   ԼԻԴ     │──────────────────────────────────────────────►
               └─────┬─────┘
   Նոր → Կապ հաստատված → Խորհրդատվություն → Փորձնական դաս → Որոշման փուլ
                     │                                         │
                     ▼                                         ▼
             Կորցրած (պատճառով)                       Գրանցված / վճարած
                     │                                         │
       30 օր հետո՝ նոր խմբի հրավեր              ավարտից հետո՝ կարծիք + խորհուրդ
                     └──────────────► նոր լիդեր ◄──────────────┘
```

Ամեն մարդ, ով որևէ կերպ կապ է հաստատում, դառնում է **լիդ**՝ մեկ քարտ իր ամբողջ պատմությամբ (հաղորդագրություններ, զանգեր, փուլեր, հայտեր, վճարումներ)։ Նույն մարդը տարբեր ալիքներից գրելիս **չի կրկնվում**. համակարգը միավորում է նրան հեռախոսահամարով, էլ. փոստով, Telegram/Instagram/Facebook ID-ով կամ կայքի հաշվով։

### Որտեղից են գալիս լիդերը (ավտոմատ)

| Աղբյուր | Ինչ է կատարվում |
|---|---|
| Կայքի «Կապ» ձև | Լիդ + հաղորդագրությունը պատմության մեջ |
| Գրանցում կայքում | Լիդ՝ կապված հաշվին |
| Հայտ դասընթացին | Լիդ + դասընթաց + ձևաչափ. հայտի կարգավիճակը փոխում է լիդի փուլը |
| Վճարում | Լիդ → «Գրանցված», ողջույնի հաղորդագրություն |
| Բաժանորդագրություն | Լիդ «բաժանորդ» պիտակով |
| WhatsApp (GREEN-API) | Ամեն նոր զրուցակից՝ լիդ, ամեն հաղորդագրություն՝ պատմության մեջ. հեռախոսից ձեր պատասխաններն էլ են գրանցվում |
| Telegram բոտ | Նույնը. `t.me/ԲՈՏ?start=instagram` հղումը նշում է աղբյուրը |
| Instagram Direct, Messenger | Նույնը (Meta webhook) |
| Lead Ads, Google Forms, Zapier, Make | `POST /api/crm/lead` |
| Զանգ, այց, միջոցառում | Ձեռքով՝ «Լիդեր → Նոր լիդ» |

## 2. Վաճառքի խողովակի փուլերը

| Փուլ | Երբ է լիդն այստեղ | Ձեր գործողությունը | Ժամկետ |
|---|---|---|---|
| **Նոր** | Դեռ չեք խոսել | Զանգ կամ անձնական հաղորդագրություն | 15–30 րոպե |
| **Կապ հաստատված** | Խոսել եք, բայց հանդիպում չկա | Հրավեր 15 րոպեանոց անվճար խորհրդատվության | 1–2 օր |
| **Խորհրդատվություն** | Նշանակված է կամ անցկացված | Պարզել նպատակը, փորձը, ժամերը, բյուջեն. «Հաջորդ քայլի ժամը» դաշտում գրեք ամսաթիվը. համակարգը 1 օր առաջ կհիշեցնի | մինչև հանդիպումը |
| **Փորձնական դաս** | Մասնակցում է բաց/փորձնական դասի | Դասից 1 օր հետո հարցնել տպավորությունը | 1 օր |
| **Որոշման փուլ** | Գիտի գինը, մտածում է | Պատասխանել առարկություններին, առաջարկել ամսական վճարում, նշել մեկնարկի ամսաթիվը | 2–3 օր |
| **Գրանցված** | Վճարել է | Ողջույն, դասացուցակ. ավարտից հետո՝ կարծիք | ավտոմատ |
| **Կորցրած** | Հրաժարվեց կամ լռում է | **Միշտ գրեք պատճառը** (գին, ժամանակ, այլ կենտրոն…). սա ձեր ամենաարժեքավոր տվյալն է | — |

**Կանոն.** բաց փուլում գտնվող լիդը պետք է միշտ ունենա **հաջորդ քայլ և ամսաթիվ**։ Եթե չունի, համակարգն ինքը կստեղծի առաջադրանք։

## 3. Ալգորիթմները

### 3.1 Արագ արձագանք (speed-to-lead)
1. Լիդը ստեղծվում է → **անմիջապես** ստանում է «welcome» ձևանմուշը այն ալիքով, որով գրել է։
2. Ստեղծվում է առաջադրանք «Զանգահարել՝ Անուն (հեռախոս)»՝ 30 րոպե ժամկետով (փոխվում է կարգավորումներում)։
3. Դուք ստանում եք WhatsApp ծանուցում հղումով։
4. Վահանակում «Դեռ չեն ստացել պատասխան» ցուցակը ցույց է տալիս, թե ով է սպասում և որքան ժամանակ։

Որքան արագ եք պատասխանում, այնքան ավելի հավանական է գրանցումը. մարդը դեռ հիշում է, թե ինչու գրեց, և դեռ չի դիմել մրցակցին։ CRM-ը չափում է **առաջին արձագանքի միջին ժամանակը**. նպատակը՝ 15 րոպեից պակաս աշխատանքային ժամերին։

### 3.2 Լիդի գնահատում (0–100 միավոր)

| Գործոն | Միավոր |
|---|---|
| Աղբյուր՝ հայտ դասընթացին | +30 |
| Աղբյուր՝ ընկերոջ խորհուրդ / այց | +25 |
| Աղբյուր՝ զանգ, միջոցառում | +20 |
| Աղբյուր՝ «Կապ» ձև, WhatsApp, Telegram | +15 |
| Աղբյուր՝ Instagram, Facebook, Google | +10 |
| Աղբյուր՝ բաժանորդագրություն / այլ | +5 |
| Կա հեռախոսահամար | +10 |
| Կա էլ. փոստ | +5 |
| Ընտրել է դասընթաց | +10 |
| Անհատական ձևաչափ | +8 |
| Գրանցված է կայքում | +5 |
| Եկել է վճարովի գովազդից | +3 |
| Ինքն է գրել մեզ (յուրաքանչյուր հաղորդագրություն) | +5 (առավելագույնը +20) |
| Փուլ՝ կապ / խորհրդատվություն / փորձնական / որոշում | +5 / +15 / +20 / +25 |
| Վերջին ակտիվություն՝ ≤2 օր / ≤7 օր | +10 / +5 |
| Լռություն՝ >21 օր / >45 օր | −8 / −15 |

**70+ = տաք** (զանգել այսօր), **40–69 = գոլ** (հետևել այս շաբաթ), **<40 = սառը** (սնուցել բովանդակությամբ)։ Գնահատականը թարմացվում է ամեն օր, որովհետև ակտիվությունը փոխվում է։ Լիդի էջում երևում է, թե ինչից է կազմված գնահատականը։

### 3.3 Ավտոմատ հետևողականություն

| Օր | Ինչ է ուղարկվում | Պայման |
|---|---|---|
| 0 | «welcome» | միշտ, եթե կա կապի ալիք |
| 1 | «followup_1»՝ հրավեր խորհրդատվության | փուլը «Նոր» կամ «Կապ հաստատված» է, լիդը չի պատասխանել մեր վերջին հաղորդագրությանը |
| 3 | «followup_2»՝ մոտակա խմբի ամսաթիվը | նույնը |
| 7 | «followup_3»՝ մեղմ վերջին հիշեցում | նույնը |
| 45 | Փուլը → «Կորցրած» (պատճառ՝ «պատասխան չկա») | պատասխան չկա |
| +30 | «reengage»՝ նոր խմբի հրավեր | կա բաց խումբ, մեկ անգամ |

Եթե մարդը պատասխանել է, ռոբոտը **կանգ է առնում**. խոսակցությունը պետք է շարունակի մարդը։ Ամեն քայլ ուղարկվում է միայն մեկ անգամ։

### 3.4 Այլ ավտոմատացումներ
- **Հիշեցում հանդիպումից 1 օր առաջ.** «Խորհրդատվություն» կամ «Փորձնական դաս» փուլում, եթե լրացված է «Հաջորդ քայլի ժամը»։
- **Վճարում → «Գրանցված»** և ողջույնի հաղորդագրություն («won»)։
- **Հայտի կարգավիճակ → լիդի փուլ.** «Մուտքային զրույց» → Խորհրդատվություն, «Հաստատված» → Որոշման փուլ, «Վճարված» → Գրանցված, «Մերժված/Չեղարկված» → Կորցրած։
- **Կարծիքի խնդրանք** դասընթացի ավարտից հետո (վերջին 30 օրում ավարտածներին)։
- **Առաջադրանք** այն բաց լիդերի համար, որոնք չունեն պլանավորված հաջորդ քայլ։
- **Առավոտյան ամփոփում** ձեզ՝ էլ. փոստով և WhatsApp-ով. այսօրվա առաջադրանքներ, տաք լիդեր, երեկվա թվեր։

### 3.5 Ալիքի ընտրություն
Համակարգը պատասխանում է այն ալիքով, որով մարդը **վերջին անգամ գրել է**։ Եթե այդ ալիքը հասանելի չէ, ընտրում է հերթականությամբ՝ WhatsApp → Telegram → Instagram → Messenger → էլ. փոստ։ Instagram-ով և Messenger-ով կարելի է գրել միայն մարդու վերջին հաղորդագրությունից 24 ժամվա ընթացքում (Meta-ի կանոն)։

### 3.6 Աղբյուրի հաշվառում (UTM)
Կայքը հիշում է, թե որտեղից է եկել այցելուն (`utm_*` պիտակներ, `gclid`/`fbclid`, կամ արտաքին կայքի հասցե) 90 օր։ Երբ նա հետագայում լրացնում է ձև, լիդը ստանում է այդ աղբյուրը։ Վահանակում «Աղբյուրներ» բաժինը ցույց է տալիս լիդեր → գրանցում % → եկամուտ յուրաքանչյուր աղբյուրից։

## 4. Ամենօրյա և շաբաթական ռեժիմ

**Ամեն առավոտ (15–20 րոպե)**
1. Բացել **CRM → Վահանակ**։
2. «Դեռ չեն ստացել պատասխան»՝ գրել/զանգել բոլորին։
3. «Այսօր անել»՝ կատարել և նշել ✓։
4. Յուրաքանչյուր զանգից հետո՝ «Զանգ կամ նշում» և փոխել փուլը։

**Ամեն երկուշաբթի (30 րոպե)**
1. **Վաճառքի խողովակ**՝ ով է մնացել նույն փուլում 7+ օր։
2. **Աղբյուրներ**՝ որ ալիքն է բերում գրանցումներ, ոչ միայն լիդեր։
3. **Կորցրածների պատճառները**՝ եթե կրկնվում է «գինը», առաջարկեք ամսական վճարում կամ փոքր խումբ, եթե «ժամը»՝ ավելացրեք երեկոյան/շաբաթ օրվա խումբ։
4. Պլանավորել շաբաթվա բովանդակությունը և մեկ զանգվածային ուղարկում (ոչ ավելի)։

### 5.1 Առաջարկը (ինչու ընտրել ձեզ)
- Կենդանի առցանց դասեր **փոքր խմբերով (6–12)**, ոչ ձայնագրություններ։
- **10 տարվա փորձ** ծրագրավորման մեջ և 2016-ից դասավանդում։
- Գործնական նախագիծ փորձապանակի համար և **վկայական**. ԿԳՄՍՆ երաշխավորությունը ստանալուց հետո ընդգծեք այն ամենուր։

- Եռալեզու (ՀԱՅ/РУС/ENG). սա բացում է նաև ռուսախոս և սփյուռքի լսարանը։

## 7. Միացում (մեկ անգամ)

1. **Տվյալների բազա.** Deploy-ի ժամանակ `npm run db:push`-ը ավտոմատ ստեղծում է CRM-ի աղյուսակները։
2. **Ներմուծում.** Առաջին անգամ **CRM → Վահանակ** բացելիս կայքի բոլոր գրանցվածները, հայտերը, նամակներն ու բաժանորդները ավտոմատ դառնում են լիդեր, առանց որևէ մեկին հաղորդագրություն ուղարկելու։
3. **Գաղտնի բանալիներ** (webhook token-ներ, `CRM_API_KEY`) ստեղծվում են ավտոմատ և երևում են **Ավտոմատացում և ալիքներ** էջում։ Vercel-ում պետք է ավելացնել միայն ծառայությունների բանալիները.

| Փոփոխական | Որտեղից վերցնել | Ինչի համար |
|---|---|---|
| `GREEN_API_ID_INSTANCE`, `GREEN_API_TOKEN`, `GREEN_API_URL`, `GREEN_API_ADMIN_PHONE` | console.green-api.com → Instance (`apiUrl`) | WhatsApp (ուղարկում և մուտքային). հեռախոսում պահված կոնտակտները լիդ չեն դառնում |
| `TELEGRAM_BOT_TOKEN` | Telegram → @BotFather → /newbot | Telegram բոտ |
| `META_PAGE_TOKEN`, `META_APP_SECRET` | developers.facebook.com → ձեր App | Instagram Direct, Messenger |

4. Բանալիներն ավելացնելուց և redeploy-ից հետո **Ավտոմատացում և ալիքներ → «Միացնել webhook-ները»**. կայքն ինքը կկարգավորի GREEN-API-ն և Telegram բոտը։ Ամենօրյա ավտոմատացումն էլ է ստուգում և վերականգնում դրանք։
5. **Ամենօրյա ավտոմատացում.** `vercel.json`-ում `/api/cron/crm`՝ ամեն օր 10:30-ին (Երևանի ժամով)։

## 8. Կանոններ և պատասխանատվություն

- Գովազդային հաղորդագրություններ ուղարկեք միայն նրանց, ովքեր **իրենք են կապ հաստատել** կամ համաձայնություն են տվել։ Ամեն գովազդային նամակ ունի «հրաժարվել» հղում. հրաժարվածները ավտոմատ դուրս են մնում ուղարկումներից։
- **WhatsApp.** GREEN-API-ն աշխատում է ձեր սովորական համարով. շատ հաղորդագրություններ անծանոթներին կարող են հանգեցնել համարի արգելափակման։ Պահեք օրական սահմանը (կարգավորումներում՝ 80) և զանգվածային ուղարկումները՝ շաբաթը մեկից ոչ ավել։
- **Instagram/Messenger.** միայն 24 ժամվա ընթացքում (համակարգն ինքն է ստուգում)։ Իրական օգտատերերի համար Meta-ն պահանջում է App Review։
- **Անձնական տվյալներ.** CRM-ը պահում է անուն, հեռախոս, էլ. փոստ և նամակագրություն։ Թարմացրեք կայքի «Գաղտնիություն» էջը՝ նշելով, որ տվյալները օգտագործվում են կապ հաստատելու և ուսման վերաբերյալ տեղեկացնելու համար, և որ մարդը կարող է խնդրել ջնջել դրանք (լիդի էջում՝ «Ջնջել»)։ Ճշգրիտ ձևակերպման համար խորհրդակցեք իրավաբանի հետ։
