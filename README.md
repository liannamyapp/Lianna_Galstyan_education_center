# Լիաննա Գալստյան · Կրթական կենտրոն — կայք

Եռալեզու (ՀԱՅ / РУС / ENG) կայք՝ ադմին վահանակով, անձնական էջերով, առցանց վճարումներով (Idram, բանկային քարտ), վկայականների ստուգմամբ և բլոգով։

Կայքի ամբողջ բովանդակությունը փոխվում է **ադմին վահանակից** (`/admin`), առանց ծրագրավորողի։ Այնտեղից կարող եք՝

| Բաժին | Ինչ է անում |
|---|---|
| Վահանակ | Նոր հայտեր, այս ամսվա եկամուտը, **առաջիկա 14 օրվա սպասվող վճարումները** և ուշացումները |
| Ուղղություններ | Նոր մասնագիտություն (օր.՝ «Դիզայն»): Կայքում ավտոմատ հայտնվում է նոր քարտ և ֆիլտր |
| Դասընթացներ | Ավելացնել/խմբագրել դասընթաց, **խմբակային և անհատական գներ** (ամսական և միանգամյա), ամսական վճարումների քանակ, ժամեր, մոդուլներ, նկար, հրապարակել/թաքցնել |

| Հայտեր | Հայտի կարգավիճակ, ձևաչափ (խմբակային/անհատական), անհատական ունկնդրի մեկնարկը և Zoom հղումը, վճարման գրաֆիկը, ունկնդրին ավտոմատ նամակ, դասերի առաջընթաց |

### Ինչն է աշխատում ինքնաբերաբար

- **Ձևաչափ.** դիմորդը հայտի ժամանակ ինքն է ընտրում խմբակային (50 000 ֏/ամիս) կամ անհատական (125 000 ֏/ամիս) տարբերակը։ Դասընթացի էջում երկուսը համեմատված են կողք կողքի։
- **Վճարման գրաֆիկ.** անձնական էջում ունկնդիրը տեսնում է բոլոր ամիսները (վճարված/սպասվող), հաջորդ վճարման օրը, մնացած օրերը և վճարումների ամբողջ պատմությունը։ Վճարում է մեկ սեղմումով։
- **Հիշեցումներ.** ամեն օր առավոտյան համակարգը ստուգում է վճարումները և ուղարկում.
  - 5 օր առաջ՝ հիշեցում;
  - վճարման օրը՝ «այսօր վճարման օրն է»;
  - 7 օր ուշացումից հետո՝ ծանուցում, որ դասերի և տեսադասերի մուտքը դադարեցված է (ձեզ էլ է գալիս ցուցակը)։
  Նամակները գնում են էլ. փոստով, իսկ GREEN-API միացնելու դեպքում՝ նաև WhatsApp-ով։ Օրերի քանակը փոխվում է «Կարգավորումներ»-ում։ Վճարումից անմիջապես հետո մուտքը վերականգնվում է։
- **Տեսադասեր.** ունկնդիրը դիտում է դասերը անձնական էջում, իսկ Google Drive-ի կամ վերբեռնված ֆայլերի դեպքում կարող է նաև ներբեռնել։ Մուտք ունեն միայն վճարած ունկնդիրները։
- **Խմբեր.** կարգավիճակը փոխվում է ինքնաբերաբար՝ «Լրացված», երբ տեղերը վերջանում են, «Ընթացքում»՝ մեկնարկից հետո, և «Ավարտված»՝ դասընթացի ավարտից հետո։
- **Չավարտված վճարումներ.** 2 օրից ավելի սպասող վճարումները փակվում են ինքնաբերաբար։

> **Գնի փոփոխություն։** Նոր գինը կիրառվում է նոր հայտերի համար։ Արդեն կնքված պայմանագրերի գինը չի փոխվում, այն պահվում է յուրաքանչյուր վճարման հետ։

## Ինչպես տեղադրել կայքը (մոտ 30 րոպե, ամսական 0 դրամ սկզբում)

Անհրաժեշտ է 3 անվճար հաշիվ՝ **GitHub**, **Vercel** (հոսթինգ), **Neon** (տվյալների բազա)։

### 1. Տվյալների բազա — Neon
1. Գրանցվեք https://neon.tech (կարող եք Google հաշվով)։
2. **Create project** → Region՝ *Europe (Frankfurt)*։
3. Պատճենեք **Connection string**-ը (`postgresql://…?sslmode=require`)։ Սա ձեր `DATABASE_URL`-ն է։

### 2. Կոդը GitHub-ում
1. https://github.com → **New repository** → անունը՝ `lg-academy` → *Private*։
2. **uploading an existing file** հղումով քաշեք այս թղթապանակի ամբողջ պարունակությունը (բացի `node_modules`-ից, եթե կա)։

### 3. Հոսթինգ — Vercel
1. https://vercel.com → **Sign up with GitHub** → **Add New → Project** → ընտրեք `lg-academy` → **Import**։
2. **Environment Variables** բաժնում ավելացրեք (տե՛ս `.env.example`).

| Անուն | Արժեք |
|---|---|
| `DATABASE_URL` | Neon-ի connection string-ը |
| `NEXT_PUBLIC_SITE_URL` | կայքի հասցեն, օր.՝ `https://lianna.am` (սկզբում՝ `https://lg-academy.vercel.app`) |
| `AUTH_SECRET` | ցանկացած երկար պատահական տող (40+ նիշ) |
| `ADMIN_EMAIL` | ձեր էլ. փոստը՝ ադմին մուտքի համար |
| `ADMIN_PASSWORD` | ադմինի գաղտնաբառը (ամուր) |
| `ALLOW_TEST_PAYMENTS` | `true` — մինչև բանկի/Idram-ի պայմանագիրը (թեստային վճարում) |
| `CRON_SECRET` | ցանկացած երկար պատահական տող. պաշտպանում է ամենօրյա ավտոմատացումը (հիշեցումներ և այլն) |

3. **Build Command** դաշտում գրեք․ `npm run db:push && npm run db:seed && npm run build`
4. **Deploy**։ 2–3 րոպեից կայքը պատրաստ է։
5. Մուտք գործեք `/hy/login` ձեր `ADMIN_EMAIL`/`ADMIN_PASSWORD`-ով → վերևում կհայտնվի «Ադմին»։

> `db:seed`-ը ստեղծում է ադմինին, «Ծրագրավորում» ուղղությունը, ՖՎԾ-01 և ԲՎԾ-01 դասընթացները, ՀՏՀ-ն և փաստաթղթերը։ Կրկնակի աշխատեցնելը անվտանգ է. ձեր փոփոխությունները չեն վերագրվում։

### 4. Նկարների և տեսադասերի պահոց (պարտադիր Vercel-ում)
Vercel → Project → **Storage → Create → Blob** → Connect։ `BLOB_READ_WRITE_TOKEN`-ը կավելանա ավտոմատ։ Սրանից հետո ադմինից վերբեռնված նկարներն ու տեսանյութերը կպահվեն։

> **Տեսադասերի մասին.** Blob-ի անվճար ծավալը փոքր է (մոտ 1 ԳԲ), իսկ մեկ ժամվա տեսանյութը կարող է 0,5–1 ԳԲ լինել։ Ամենաէժան տարբերակը՝ տեսանյութը վերբեռնել **Google Drive** (հասանելիություն՝ «Anyone with the link») կամ **YouTube**-ում՝ որպես *Unlisted*, և ադմինում տեղադրել հղումը։ Drive-ի դեպքում ունկնդիրը կկարողանա նաև ներբեռնել տեսանյութը։

**Ամենօրյա ավտոմատացում.** `vercel.json`-ում արդեն նշված է, որ Vercel-ը ամեն օր 10:00-ին (Երևանի ժամով) կանչի `/api/cron/billing`-ը։ Լրացուցիչ ոչինչ անել պետք չէ, միայն համոզվեք, որ `CRON_SECRET`-ը ավելացված է։

### 5. Էլ. նամակներ (Gmail-ով, անվճար)
1. Google հաշվում միացրեք **2-Step Verification**։
2. https://myaccount.google.com/apppasswords → ստեղծեք «App password»։
3. Vercel-ում ավելացրեք․
   - `SMTP_HOST=smtp.gmail.com`, `SMTP_PORT=465`
   - `SMTP_USER=ձեր@gmail.com`, `SMTP_PASS=16-նիշանոց app password`
   - `MAIL_FROM=Լիաննա Գալստյան <ձեր@gmail.com>`

Առանց SMTP-ի կայքն աշխատում է, բայց նամակները չեն ուղարկվում։

Ի՞նչ նամակներ են գնում ավտոմատ։
- **Ունկնդրին.** գրանցում, հայտի ընդունում, վճարման հաստատում, վճարման հիշեցումներ, նոր տեսադաս, հայտի կարգավիճակի փոփոխություն, կարծիքի հրապարակում, գաղտնաբառի վերականգնում։
- **«Կապ» էջից գրողին.** «Ստացանք ձեր նամակը» և ձեր պատասխանը։
- **Ձեզ.** նոր հայտ, վճարում, կարծիք, հաղորդագրություն, ուշացած վճարումների ցուցակ։

### 6. WhatsApp ծանուցումներ (ոչ պարտադիր)
GREEN-API-ում ստեղծեք instance և ավելացրեք `GREEN_API_ID_INSTANCE`, `GREEN_API_TOKEN`, `GREEN_API_ADMIN_PHONE` (օր.՝ `37477053446`)։ Դրանից հետո ձեզ կգան նոր հայտերի և վճարումների մասին ծանուցումներ, իսկ ունկնդիրներին՝ վճարման հիշեցումներ WhatsApp-ով (եթե նրանք նշել են հեռախոսահամար)։

### 7. Իրական վճարումներ
Երբ պայմանագիր կկնքեք (ԱՁ-ն բավարար է).

**Idram.** Դիմեք Idram Merchant-ին, ստացեք `IDRAM_REC_ACCOUNT` և `IDRAM_SECRET_KEY`։ Idram-ին տվեք․
- RESULT_URL՝ `https://ձեր-կայքը/api/payments/idram`
- SUCCESS_URL՝ `https://ձեր-կայքը/hy/pay/result`
- FAIL_URL՝ `https://ձեր-կայքը/hy/pay/result?e=1`

**Բանկային քարտ (Ameriabank vPOS).** Ստացեք `AMERIA_CLIENT_ID`, `AMERIA_USERNAME`, `AMERIA_PASSWORD`։ Թեստի ժամանակ `AMERIA_TEST=true` (բանկի թեստային միջավայրում գումարը հաճախ պետք է լինի 10 ֏), աշխատանքային ռեժիմում՝ `false`։

Հետո դրեք `ALLOW_TEST_PAYMENTS=false` և **Redeploy**։

### 8. Սեփական դոմեն (օր.՝ lianna.am)
Vercel → Project → **Settings → Domains → Add**։ Գրանցողի մոտ DNS-ում ավելացրեք Vercel-ի տված A/CNAME գրառումները։ Թարմացրեք `NEXT_PUBLIC_SITE_URL`-ը և Redeploy արեք։

## Տեխնիկական տվյալներ (ծրագրավորողի համար)

- **Stack.** Next.js 15 (App Router, Server Actions), React 19, TypeScript, Tailwind CSS 4, Drizzle ORM + PostgreSQL, JWT session (jose), bcrypt.
- **Տեղական աշխատանք.** `cp .env.example .env` → լրացնել → `npm i && npm run db:push && npm run db:seed && npm run dev`
